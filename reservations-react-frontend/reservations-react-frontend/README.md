# Reservations React Frontend

React frontend for the PID Reservations backend.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Default backend URL: `http://localhost:8085`.

## Features

- Login/signup with JWT storage
- Public show catalogue with search, sorting, pagination, filters
- Show details, representations, availability, reservations, reviews
- Member profile and my reservations
- Admin dashboard with CRUD screens for shows, users, roles, locations, artists, prices, collaborations and more
- CSV import/export and external import buttons
